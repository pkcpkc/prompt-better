# Generable Prompts & Structured Outputs Guide

`AIPromptCore` offers first-class support for type-safe structured generation using Apple's `@Generable` macro and compiled prompt configurations from `prompt-better`.

---

## 1. Type-Safe Structured Generation (`@Generable`)

Apple Foundation Models support guided decoding to generate responses strictly matching a Swift schema:

```swift
import FoundationModels
import AIPromptCore

@Generable
struct CustomerSupportTicket {
    var category: String
    var priority: String
    var sentiment: String
    var recommendedAction: String
}
```

### In-Process Execution with `client.chat.completions`

```swift
let client = AppleOpenAIClient.shared

let ticket: CustomerSupportTicket = try await client.chat.completions.create(
    messages: [
        .init(role: "user", content: "I was charged twice for order #12345 and need a refund immediately!")
    ],
    generating: CustomerSupportTicket.self
)

print("Priority: \(ticket.priority)") // e.g. "High"
print("Action: \(ticket.recommendedAction)")
```

## 2. Parameterized Prompt Templates (`GenerableWithPrompt`)

Combine prompt configuration templates compiled by `prompt-better` with `@Generable` Swift types:

```swift
struct MeetingActionItems: GenerableWithPrompt {
    static var promptName: String { "extract_action_items" }

    // Schema generated by AFM
    @Generable
    struct Schema {
        var summary: String
        var tasks: [String]
        var owners: [String]
    }
}

// Generate directly with parameter dictionary
let client = AppleOpenAIClient.shared
let result = try await client.prompts.generate(
    type: MeetingActionItems.self,
    parameters: [
        "transcript": "Alice will prepare the presentation. Bob will review the finances by Friday."
    ]
)
```

---

## 3. Advantages Over Raw JSON Decoding
1. **Zero Hallucination of Schema**: Constrained decoding guarantees that every field conforms to the Swift property types at the token sampling level.
2. **Zero HTTP Overhead**: Generation occurs directly within the app process memory using the Apple Silicon Neural Engine.
3. **No Regex / JSON Parsing Errors**: Native FoundationModels grammar guarantees valid structured output without post-processing failures.
